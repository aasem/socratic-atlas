# Socratic Dialogue Atlas

Twenty-four Platonic dialogues set side by side: the question, setting and scene, method, where each one arrives, the strongest pushback, what became of the speakers, and the intended lesson. A timeline also arranges them as a single plot, from the young Socrates of the *Parmenides* (c. 450 BCE) to the hemlock (399 BCE).

## Files

| File | What it is |
|---|---|
| `index.html` | The whole atlas: content, styles and script. |
| `readings.js` | **My reading** for each dialogue. This is the part to edit. |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are. |

## Editing "My reading"

Either way works:

1. **On GitHub:** open `readings.js`, click the pencil icon, change the text between the backticks, and commit. A blank line starts a new paragraph. Change `READINGS_AUTHOR` to your own name.
2. **On the page:** click **Edit** under any dialogue, write, and **Save**. These edits stay in your browser only. When you're done, click **Copy readings.js** above the entries, then paste that over `readings.js` on GitHub and commit.

## Publishing with GitHub Pages

In the repository, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save. The site will appear at `https://aasem.github.io/socratic-atlas/` within a minute or two.
